# v47 轻量 Schema 草稿预试结果

本轮不采用 v47。24 次同期 A/B Schema-only 预试已全部执行、审阅且独立复核；
B 没有满足生成可靠性、合理提案数、合理联合一致性及业务保护门槛。
产品保留 v44，候选运行接线已撤下；没有启动后续 112 次端到端对照，没有补跑。
实际使用 **24/136 次公共生成请求**，实际解析能力和默认单输入之外的泛化能力均未测。

计数以同期最终提案为依据；“新增”表示相对本次 A 出现，不表示历史上从未见过。
不能因 B 的 SD-WAN 全部失败就报告该错误已消除。B 的 10 份成功提案未见根粒度错误，
其中 8 份含重复实体且置于数组；这支持成功子集中的行为观察，不证明隐式根机制确保正确。

[B 命名审计](schema-draft-v47-naming-review.json)逐字段复核了 153 个属性：
139 个来源名称、14 个语义兜底（9.15%；12 个无直接标签，2 个拆分子项），共 141 条引用。
135 个来源名称完整忠实；2 个将动态限定拆为独立字段，另 2 个只取共同标签而未捕获动态
限定，列为命名政策偏离。后者保留了链路类别，业务审阅未据此直接判遗漏错误。
没有发现半词、错误邻列引用或无依据同义词兜底，但不能把这等同于编译器能够证明标签归属。

命名差异有减少信号：同义差异由 3/4 变为 2/5，但有效分母不同且样本很少。
剩余两对涉及必要兜底容器，如 `/hour_statistics` 与 `/hour_sections`，
以及 `/port_channels` 与 `/port_channel_groups`。兜底名称集合另有 OSPF 的覆盖差异；
集合不等不自动等同字段改名。确定性标签命名没有约束 required、类型、说明或实体判断。

自动同路径差异中，A 标量类型、required、约束分别影响 0/4、0/4、0/4 pair；
B 分别为 1/5、0/5、0/5。路径集合差异 A 4/4、B 3/5；说明文字变化 A 4/4、B 4/5。
零同路径差异不表示整体契约稳定：上游容器名称或结构变化会减少可比较节点。
完整受影响 pair、节点数及比较分母保留于数值报告。

## 协议与输出预算

A 的两个失败分别是 SD-WAN 连续无工具和 OSPF 工具参数协议终止。
OSPF 先有 5 次业务校验拒绝，随后错误入参达到协议止损门槛；
保留业务拒绝与框架参数拒绝的区分，不用异常文字猜测类别。
B 两个失败均为 SD-WAN：各连续四次无有效工具回复后停止。

## 门槛与最终决定

| 预试条件 | 结果 |
| --- | --- |
| B 生成及复验 12/12、审阅完整 | 10/12，失败；审阅完整 |
| U_B >= U_A | 5 < 6，失败 |
| J_B >= 1/6 且不低于 A | 0/6，失败 |
| 无新增或扩大业务机制 | Port-channel 拆分、HP 说明错误，失败 |
| 根粒度不扩大 | 成功子集未见扩大，SD-WAN 不可判断 |
| 无需修改实现才能继续 | 未发现本轮行为实现缺陷；不改变其他失败结论 |

独立合成示例证明编译、约束保留与阶段隔离成立；真实模型也大多采用了来源命名，
并在部分成功用例减少命名差异。但业务合理性未保持，合理联合一致性没有改善，
输出截断仍可阻止提交。本轮没有实际解析证据，不能宣称局部或综合有效并采用。

按既定规则保留 v44 和此前可靠性修复，撤下候选运行接线，保留独立诊断及全部脱敏结果。
没有自动追加输出预算、改变 thinking、重试失败请求或开始下一项优化。
这些门槛是本轮工程决策规则，不是统计显著性证明。
