## 判断

离线机制成立：更大预算正确发送，初始采样与消息没有变化。实际生成由历史 0/4 变为
2/4，说明本轮出现了成功工具提交；但仍有一半请求未冻结，唯一另一份成功提案还有明确
业务错误。增加预算没有稳定消除推理耗尽，且成本和耗时明显增加，不能作为已验证修复。

后续值得单独检验的是推理投入与工具提交行为，以及复杂多行表头限定和空列覆盖。
这些是下一轮方向，本轮不调整推理参数、提示或重试，不自动开始下一项实验。
