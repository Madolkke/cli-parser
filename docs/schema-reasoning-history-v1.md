# Schema 原生推理历史恢复实验

目标仍为 SD-WAN 稳定生成，同时保护历史 14 例默认输入范围。位置辅助实验已失败并撤线，
不拼接其结果。本候选处理已证实的运行机制：无工具回复被恢复到调用前的上下文，且锁定的
OpenAI formatter 忽略 Thinking，后续请求没有接续前轮推理。四轮预算不能解释为累计推理。

2026-09-18 核对的 [DeepSeek 文档](https://api-docs.deepseek.com/guides/thinking_mode)
要求带 tools 的对话传回此前 reasoning_content，包括没有工具调用的轮次。其默认推理为
high，thinking 模式下 temperature 无效；配置仍记录 temperature=0，不能据此保证确定性。
文档支持使用原生历史通道，但没有证明传回截断推理会消除业务判断循环。

## 机制与范围

只在官方 api.deepseek.com 的 Schema 阶段、未显式关闭 thinking 时使用私有 formatter。
保留原 OpenAI 请求行及文本格式，仅给 assistant 分段加入其自身的 reasoning_content。
首轮没有历史，请求不变；TTP、外部注入、其他供应商和显式关闭推理仍用原路径。
AgentScope 会把多轮调用和结果累积在同一条 assistant 消息，必须按工具结果及 Hint 边界
关联推理，不能把整条消息的思考附到每一次工具调用上。合法 Schema 拒绝的既有历史也按
这一供应商协议传回推理；因此普通业务修复请求可能改变，不把影响范围虚称为仅 SD-WAN。

原无工具分支仍执行协议及重试计数。只在原始供应商回复已完整返回、length、有推理、
无正文且无任何原始工具调用时，保留本轮新增 Thinking，加入独立 assistant 消息，使用
原固定提醒进入已有重试。第四次无工具照常停止；不增加调用、预算或改变推理强度。
取消、未完成流、异常、普通文本和含工具的截断回复不能走此恢复；截断工具防护保持。

推理来自当前模型请求内存，按原通道原样传回，不来自 Trace、observer、标准答案，
不抽取字段、不总结、不改写为用户指令。模型可能延续错误判断，真实审阅仍是必要条件。
首份合法 Schema 冻结、v48 提示及工具签名保持不变。无编译、缓存、额外 Agent 或确认。

实际发送的推理计入现有近似 Token 估算。在原生压缩执行前检查完整系统、上下文和工具，
推理历史不能触发额外摘要调用。阈值为初始上下文比例、原生压缩阈值、上下文减输出预留
三者最小值；达到阈值、已有摘要或不能可靠计数时，以已有 model_context_budget 分类
结束，不能静默截断历史、丢掉原任务或回到更小样本。计数仍为近似值，不宣称供应商精确
Token 保证。正常无推理上下文沿用原生行为，deadline 与取消继续生效。

安全观察 `cli_parser.schema.reasoning_history` 仅保存状态、轮次、字符数、块数及估算数量，
不保存思考正文。额外运行时标识 `schema-reasoning-history-v1` 与 v48 提示版本分别登记。

## 离线验收

验证初次及 TTP 请求不变、后续原生推理顺序与内容、合并消息边界、合法拒绝与协议拒绝、
纯推理和截断工具的区别、流式/非流式完成、取消、网络重试、第四次停止、无历史污染。
验证实际发送内容参与计数、压缩前容量边界不额外请求摘要、失败分类和脱敏产物。
完整 pytest、JavaScript、Ruff、格式、diff，以及默认/full preflight与baseline必须通过。
v48 提示、任务、工具、TTP 正文和标准四件套不改；只有新候选接线及诊断发生变化。

## 分阶段真实验证

标准入口 `scripts/run_test_sets.py run --mode schema-only`，deepseek-v4-flash，非流式，
temperature0、8192/128000、HTTP120秒、模型重试2、1800秒/26轮，其他逐项匹配v48记录。
默认001、各四次独立生成、同批内存输入快照、并发四。运行前验证 Laminar 写入、flush、
回读及正文访问，记录 revision、dirty、输入选择与配置；不新增模型探针。

1. SD-WAN ID11四次全部生成及复验、业务可接受、适用规则通过且证据完整，才进入保护。
2. ID1,3,5,6,7,9,10,13,14,16,17,18,19 各四次，共52次。生成复验52/52，每例业务及政策
   通过数不得低于v48；不得新增或扩大错误机制。ID10/13/14各4/4联合通过且各6/6 pair
   合理、完整契约及说明语义一致；其他命名、层级及契约变化独立审阅。

最多56次公共请求，不补跑。首阶段失败就停止并撤下候选接线；保护不通过也不得采用。
不以Schema合法替代业务及规则，不以稳定三例替代其余13例保护。出现实现行为缺陷停止
该批，不修正后继续拼接。逐条及有效pair使用metrics v2、review v2；失败与新增问题独立复核。
正文只通过已授权 Laminar 只读通道在分析内存处理；本地仅保存受限分类、数量、路径及标识。

没有同期对照，旧模型别名不证明后台版本固定；不以小样本或历史比较宣称统计因果。
可解析性、Hard与默认单输入以外的泛化未测。完整目标达标前不标为已解决。
