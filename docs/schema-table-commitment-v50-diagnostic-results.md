表头及值槽存在而值为空时，required string 可以忠实表达空字符串；末列 optional
也未要求丢弃已存在的空槽。本批没有仅因 required 差异判业务失败。所有 description
均已只读审阅；六对未发现说明改变值保真、空槽、单位或捕获边界的要求，
