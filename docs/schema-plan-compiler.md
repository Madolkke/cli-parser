## 模型与程序的职责

模型提交 version=1 的 SchemaPlan，识别 object、collection、value 的实体关系，
以及原文标签、实例区间和值槽。根 record 的实例由程序按输入建立；每个输入一个根。
来源位置是实际发送片段中的 Unicode 字符半开区间，不是编码字节或 JSON 转义后的偏移。
采样省略区域不能作为证据；原文本中恰好等于省略标记的内容不自动视为采样。

程序验证树、来源坐标、父实例归属和重叠，规范可靠英文标签为小写 snake_case，
保留词序、缩写和限定。无标签、非法名字、真实冲突或共享标签拆分时才允许语义名称兜底。
冲突不能静默覆盖、截断或编号；正常多行限定属于 label_refs，消歧额外限定属于 qualifier_refs。

类型默认 string；只有完整证据中的 count 值全为无前导零、单位、空槽或占位符的
非负十进制整数时才编译 integer。时间、版本、标识符、单位和值内符号保留。
不生成任意 enum、数值范围、长度或数组数量约束；不接受模型自由 description。
说明由来源、业务角色及 capture 模式生成固定文案；title 省略。

required 从完整输入和已列父实例中的真实值槽计算。明确空槽算存在；采样、
证据不完整或达到引用上限时保守可选。枚举完整性仍来自模型判断，程序不会宣称
已经证明所有业务实体被枚举；反馈固定 enumeration_verified=false。

计划上限64KiB、256节点、16层、1024来源引用。超限拒绝，不悄悄删字段。
字段可以用不完整代表证据建模，此时必填性与计数类型保守处理；长表优先覆盖全部业务字段，避免穷举实例耗尽固定输出预算。未显示任何可靠正文的采样输入仍保留不可引用的空元数据及根实例，不得从输入数量删除。明确空集合使用真实表头或空表标记，
不虚构元素；完全没有可观察叶子的 Schema 仍受原 no_leaf_fields 门禁约束。

## 冻结与隔离

B 的 submit_schema_plan 合法后立即编译、校验并冻结。C 的同名工具只保存待确认结果，
完整 Schema 返回模型；confirm_schema_plan 只能在后续模型轮次无参冻结，同批工具调用不能跳过复核。重交开始即撤销旧待确认状态，
包括被框架参数层拒绝的重交。取消、超时、无确认均不能成功，所有调用消耗现有预算。

TTP 仅接收冻结 Schema 与自己的原始输入采样，不接收计划、来源索引或 Schema 历史。
外部 generate_from_schema 仍校验调用方原 Schema，不执行计划编译或确认。
Schema 工具事实中的结构接受与模型确认都不是确定性业务验收。

独立测试分别验证来源与编译机制、实际 OpenAI SDK/AgentScope 请求及阶段隔离。
同一计划产生相同契约不证明同一输入每次产生相同计划；真实审阅分别评价这两个层次。
