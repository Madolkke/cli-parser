# v51 纯推理截断后的限定归属恢复候选

目标是让 SD-WAN 生成业务可接受的 Schema，并验证原有 13 个用例不劣化。
这是未采用的候选，不以工具提交成功替代业务和政策审阅。

## 证据与最小改动

v50 诊断批四次都生成合法实体数组，但一份把没有来源归属证据的限定拼入另一列。
错误出现在第二轮，尚未触发最终强制提交；只修改最后一次提交提醒覆盖不到它。
全局系统、任务、工具和多轮提醒同时叠加宽表规则没有消除问题，也无法隔离收益。
该诊断批的配置偏差与完整结果保留于
[诊断报告](schema-table-commitment-v50-diagnostic-results.md)，未作为正式验收。
当时未提交的三个源文件差异保留在
[诊断补丁](schema-table-commitment-v50-diagnostic.patch)，基于 `6d74382`。

本候选撤去全局 v50 叠加，版本为
`ttp-generator-v51-schema-length-recovery-zh-cn`。Schema 系统正文、初始任务、
工具定义、普通无工具提醒和 TTP 请求与 `6d74382` 相同。
只有官方 DeepSeek Schema 阶段已完整返回纯推理 `length`、且本轮 Thinking
符合既有保留条件时，下一条恢复提醒采用有界的新指导：保留独立列和可靠限定，
无法证明归属的孤立上层词不参与列名或 description 中的事实断言。
冲突仍用可靠限定或语义名称处理；不新增根、类型、required 政策。

既有三次修复后关闭 thinking 并强制唯一提交工具的时机、轮次及输出预算不变。
最终提醒仅要求停止和正确包络，移除“全空槽一律可选”等与系统规则竞争的指导。
模型仍可能误判来源和业务含义；纯推理历史也可能延续错误判断。这些都必须真实审阅。
不新增工具、编译器、自动重命名、业务门禁、模型切换或额外产品 Agent。

## 工程验收与观察

MockTransport 验证恢复提醒只在上述分支出现；首轮、TTP、普通文本、截断工具、
其他供应商、显式禁用 thinking、正常业务修复和外部注入保持隔离。
AST 比较验证 Schema/TTP 系统正文、任务构造和普通重试不变。
完整离线 pytest、JavaScript、Ruff、format、diff 及默认/full preflight、baseline
通过后才提交实现和启动运行。标准测试四件套不改，已有脏文件不夹带提交。

MockTransport 另复现并修复一个取消边界：框架可能消化外部取消后进入无工具重试。
runner 在事件及轮次边界检查仍未处理的外部取消，禁止后续请求；与合法冻结所用的
内部终止取消分开处理。该修复不是模型收敛收益，也不改变正常请求的提示或预算。

唯一 runner 新增严格白名单的 `forced_submission` 观察及轮次记录：只包含激活
状态、次数、固定策略和原因。它不证明请求发送、工具执行或冻结成功；旧产物缺失
该事件时为不可用，不补零。原始 length 次数须从供应商 Trace 独立核对。

业务可接受、适用政策通过且证据完整才继续。末列可用有证据的保守名称，不要求
猜出错位上层限定；未知政策证据不算通过。四次契约和命名一致性仍完整报告。

首阶段通过后，ID `1,3,5,6,7,9,10,13,14,16,17,18,19` 默认 `001.txt` 各四次。
保护要求：生成及复验 52/52，每例业务/政策通过数不得低于 v48，无新增或扩大业务
机制；ID10/13/14 各 4/4 联合通过且各 6/6 pair 合理、完整契约和说明语义一致。
这覆盖当前既有14例范围，不以三个完全稳定用例替代其他十例。

每个阶段通过 `scripts/run_test_sets.py run --mode schema-only` 执行，独立生成器，
同批内存输入快照、重复四次、全局并发四。固定 deepseek-v4-flash、temperature 0、
非流式、8192/128000、HTTP120秒、模型重试2、1800秒/26轮、TTP额度18/3；
其余 model/policy 匹配 v48。环境显式覆盖并在启动前核验，不复用错误的默认预算。
Laminar 写入、flush、回读及授权只读正文访问在运行前验证，不发额外模型探针。

全部已运行 trial 和有效 pair 使用 metrics v2/review v2 审阅；失败和新增问题独立复核。
正文只经已授权 Laminar 只读通道在分析内存处理，本地仅保留分类、数量、有界问题路径
及标识。首阶段或保护失败就停止本候选，不拼接重跑，不以 generation 4/4 宣称完成。
失败时恢复 v48 提示入口，保留独立诊断测试、观察修复和结果，另行说明未验证的运行时
候选状态。没有同期对照，历史差异不证明统计因果；Schema-only 可解析性未测。
