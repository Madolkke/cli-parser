# Schema 推理截断的限定恢复

目标是恢复 SD-WAN 的稳定 Schema 提交，同时保护已有用例的业务合理性、命名与结构。
前两轮提示实验及加大输出预算没有达到门槛。本轮保留 v48 全部提示及提交工具描述，
运行时策略单独标记 `schema-reasoning-recovery-v1`，不伪装成仅修改提示。

## 行为

锁定 AgentScope 的 OpenAI parser 未传递供应商 finish_reason。适配器在原始响应解析边界
读取长度终止、有无推理/正文/工具等受控事实，不读取 Trace、不保存推理或草稿。

仅官方 `api.deepseek.com`、Schema 阶段、调用者未显式配置推理或 extra_body 时，
连续三个模型轮次均为供应商 `length`、含推理且无正文/工具，才在下一次既有重试使用
`thinking: {type: disabled}`。普通回复、参数拒绝和业务拒绝不满足触发条件。其他供应商
与 TTP 阶段不启用该恢复；新的公共请求重新从默认行为开始。

首次调用及前两次修复保持原请求；第四次调用使用原工具、输入和提醒，仅改变供应商
thinking 参数。已有三次修复、第四次失败停止的协议计数不变。总轮数和时间不增加，
取消、超时、异常不作为成功响应，也不能使用上轮残留事实触发恢复。恢复后的合法提交
照常校验、深拷贝冻结；若随后出现合法业务拒绝，剩余 Schema 轮次继续非推理模式。

选择三次连续截断，是为了让原来能在前三次收敛的输入保留原路径。它不是按 SD-WAN
名称或输入正文分支，也不保证关闭推理后一定正确。命名、类型、required、description、
结构及约束仍由模型按 v48 政策选择；不恢复 v49，不增加编译、确认或额外模型调用。

官方依据（2026-09-18核对）：[Chat Completions](https://api-docs.deepseek.com/api/create-chat-completion)
明确支持 thinking.type=disabled；[Thinking Mode](https://api-docs.deepseek.com/guides/thinking_mode)
说明默认启用推理。模拟 transport 检验最终 JSON，真实 Trace 核对有效行为。

## 离线验收

- 三次连续条件、非连续条件、流式/非流式、真实工具及普通文本排除、显式配置排除。
- 官方域名限制、超时/取消/HTTP重试事实隔离、已有停止次数、轮次及时间预算。
- 实际 transport 验证前三次请求不变、第四次只改变 thinking；原始分析不回灌。
- 成功 Schema 原样交接 TTP；TTP 的提示、参数与工具不变，外部注入不触发恢复。
- 安全观察只记录枚举、数量和轮次；保持 runner v5、metrics v2、review v2兼容。
- 完整离线 pytest、JavaScript、Ruff、格式、diff，以及默认/full preflight和baseline。
  产品提示和工具描述逐字未变，标准测试四件套不改；已有脏文件不夹带提交。

## 分阶段真实验证

使用唯一标准入口 `scripts/run_test_sets.py run --mode schema-only`；每次独立生成器，
每批共享原始输入内存快照，全局并发4。保持 deepseek-v4-flash、非流式、temperature0、
8192/128000、HTTP120秒、模型重试2、1800秒/26轮，其他配置与 v48 相同。
启动前完成 Laminar 探针写入/flush/回读/只读正文访问，记录revision、dirty和输入路径。

1. ID11 默认001，4次。要求4/4生成复验、业务可接受、适用政策通过，全部证据完整。
2. 首阶段通过后，其余13例各4次：ID1,3,5,6,7,9,10,13,14,16,17,18,19。
   要求52/52生成复验；各例业务可接受及政策通过数不低于v48，没有新增业务机制或扩大
   原有机制。ID10/13/14仍须各4/4联合通过及6/6合理契约/说明语义一致。
   其余例命名、层级和契约分别报告；不能用相同错误的契约相等掩盖业务问题。

共56次公共请求，不补跑失败trial。首阶段不通过便停止该候选；故障证据用于后续设计，
不把修正后的请求拼接进原批次。全部trial和有效pair均通过授权只读正文在内存审阅，
本地只保存受限结论、数量和标识；未审阅及证据不足不判通过。

本轮验证边界是此前14例默认输入的 Schema 阶段。Hard、其他输入及实际解析能力不能
据此宣称已验证。目标完成需要核对上述范围所有条件；仅SD-WAN提交成功不算完成。
若该候选未通过，撤下未验证恢复行为，保留诊断证据，目标继续有效，另据证据推进。
