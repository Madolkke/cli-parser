# Schema 重复推理后的工具选择候选

本候选只针对 Schema 阶段在官方 DeepSeek 端点上出现的连续纯推理截断。
当最近一次原始回复是 `finish_reason=length`、只有 `reasoning_content`，且已连续
达到 Schema 零工具重试上限时，下一次请求将关闭 DeepSeek thinking 并把唯一工具
`submit_result_schema` 设为强制选择。该请求仍使用同一提示、输入、工具定义、预算
和重试计数；不增加轮次，也不把截断工具调用交给 JSON 修复器。
请求末尾会附加一条有界的提交检查，要求对无法可靠归属的表头保留底层标签、把全空
值槽设为可选，并避免把名称或编号字段推断为数值；它不包含评测答案或历史 Schema。

普通无工具文本、业务校验拒绝、包含截断工具调用的回复、其他供应商、TTP 阶段和
显式关闭推理的请求保持自动工具选择。首轮及未达到连续重试上限的请求仍省略
`tool_choice`。强制选择只保证模型必须产出该工具调用，提交内容仍由现有 Schema
校验器和人工评测判定，不能把工具调用成功当作业务正确。

运行时事件 `cli_parser.schema.forced_submission` 只保存触发原因、连续次数和策略版本，
不保存模型正文、推理或 Schema。若强制调用仍失败，沿用既有参数错误、业务拒绝和
终止协议；不会自动修复或冻结不合法结果。
